# Start & Stop Countdown (React + Vite)

## Run
    npm install
    npm run dev      # open the URL shown (usually http://localhost:5173)

## Build
    npm run build

## Features
- Set hours / minutes / seconds manually (starts at 00:00:00)
- Start: begins countdown (disabled while running); resumes from the stopped number
- Stop: pauses at the current number (enabled only while running)
- Reset: restarts the countdown from the time you entered
- Refresh icon: sets hours, minutes and seconds back to 00
